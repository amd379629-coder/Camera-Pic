How to run this tool:

1. Update packages and install Git & Python:
   pkg update && pkg install git python -y

2. Clone the repository:
   git clone https://github.com/amd379629-coder/Camera-Pic.git

3. Navigate to the project folder:
   cd Camera-Pic

4. Give execution permission and run the tool:
   chmod +x start.sh cloudflared
   bash start.sh
